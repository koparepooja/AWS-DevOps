k8s_docker_application
Node.js Application Deployment on Docker & AWS EKS
This project demonstrates how to build a simple Node.js application, containerize it using Docker, push the image to Docker Hub, and deploy it to an Amazon EKS (Elastic Kubernetes Service) cluster using Kubernetes manifests.

🚀 Project Overview
You will:

Install Docker
Build & push a Docker image
Create Kubernetes deployment & service configuration
Configure AWS CLI & EKS Kubeconfig
Deploy the application on EKS
Access the application via LoadBalancer
📦 Prerequisites
Ubuntu machine
Docker installed
AWS CLI installed
AWS IAM user with EKS permissions
EKS cluster already created
kubectl installed
